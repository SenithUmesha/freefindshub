# Contributing

Thanks for taking a look at FreeFindsHub.

This repository is the **public product + engineering showcase** for the project. The production source, content registry, publishing automation, private reporting, and deployment configuration live in a separate private repository.

## What belongs here

Changes to this public repository should stay focused on:

- product documentation
- architecture and engineering notes
- public screenshots or diagrams
- corrections to public links
- explanations of shipped product behavior
- portfolio/showcase improvements

## What does not belong here

Please do not add or request:

- production source code
- secrets or environment configuration
- private growth/reporting data
- privileged automation implementation
- deployment credentials
- advertising account identifiers
- unpublished content records

## Documentation changes

For Markdown changes, keep relative links valid and avoid exposing implementation details that would weaken the boundary between this showcase and the production system.

The repository's docs workflow checks Markdown files for broken local links and merge-conflict markers.
